## 1 系统需求分析

### 1.1 系统主题阐述

随着电子商务行业的快速发展，在线客服系统已成为电商平台不可或缺的组成部分。传统的人工客服模式面临着成本高、响应慢、服务质量不稳定等问题。本系统旨在开发一套基于RAG（Retrieval-Augmented Generation，检索增强生成）技术的电商智能客服系统，通过结合向量检索与大语言模型，实现高效、准确的智能问答服务。

本系统主要涉及以下角色：

2. **普通用户/顾客**：通过客服聊天界面提问，获取智能客服的自动回复。
3. **API调用者**：通过RESTful API接口调用智能客服服务，可集成到其他系统。

### 2.2 人工智能相关技术原理及模块设计

#### 2.2.1 人工智能相关技术原理

本系统核心采用 **RAG（Retrieval-Augmented Generation，检索增强生成）** 技术，这是一种结合信息检索与文本生成的AI技术架构。

**RAG技术原理：**

RAG技术的核心思想是：在生成回答之前，先从知识库中检索相关信息，然后将检索到的信息作为上下文，辅助大语言模型生成更准确、更有依据的回答。

RAG工作流程如下：

```
用户问题 --> 向量化 --> 向量检索 --> 获取相关文档 --> 构建Prompt --> LLM生成 --> 输出回答
```

**技术原理详解：**

1. **文本嵌入（Text Embedding）**
   
   文本嵌入是将文本转换为高维向量表示的过程。本系统使用SentenceTransformer模型，基于Transformer架构，将文本映射到384维向量空间。语义相似的文本在向量空间中距离较近。

   数学表示：`Embedding(text) → Vector[384]`

2. **向量相似度检索**
   
   使用余弦相似度或欧氏距离计算查询向量与知识库向量的相似度，返回最相关的Top-K个文档。

   相似度计算公式：`similarity = 1.0 / (1.0 + distance)`

3. **检索增强生成**
   
   将检索到的文档与用户问题组合，构建增强Prompt：

   ```
   Prompt = "根据以下参考知识回答问题：
            【参考知识】：{retrieved_docs}
            【用户问题】：{question}
            请用简洁的客服语气回答："
   ```

4. **大语言模型生成**
   
   将增强Prompt输入DeepSeek大语言模型，生成最终回答。

**RAG技术优势：**

- **准确性高**：基于检索到的真实知识生成回答，减少幻觉
- **可解释性强**：可以追溯回答来源
- **易于更新**：只需更新知识库，无需重新训练模型
- **成本低**：无需微调大模型，降低计算资源需求

```python
class VectorStoreService:
    def __init__(self, persist_dir="./chroma_db"):
        self.persist_dir = persist_dir
        self.embeddings = get_embeddings()
        self.db = Chroma(persist_directory=persist_dir, 
                        embedding_function=self.embeddings)
    
    def search(self, query, top_k=3, min_score=0.3):
        results = self.db.similarity_search_with_score(query, k=top_k)
        # 过滤低相似度结果
        return [doc for doc, score in results 
                if 1.0/(1.0+score) >= min_score]
```

#### 3.1.2 核心代码实现

**RAG服务核心实现（rag_service.py）：**

```python
from langchain_core.prompts import PromptTemplate
from langchain_openai import ChatOpenAI
from vector_store import VectorStoreService

class RAGService:
    """RAG检索增强生成服务"""
    
    def __init__(self, config: Config):
        self.config = config
        self.vector_store = VectorStoreService(config.persist_dir)
        self.rag_chain = None
    
    def initialize(self) -> None:
        """初始化RAG服务"""
        # 初始化向量存储
        self.vector_store.initialize()
        
        # 初始化大语言模型
        llm = ChatOpenAI(
            model=self.config.deepseek_model,
            api_key=self.config.deepseek_api_key,
            base_url=self.config.deepseek_base_url,
            temperature=self.config.temperature
        )
        
        # 定义Prompt模板
        prompt = PromptTemplate(
            template="""你是专业的电商智能客服，严格根据【参考知识库】回答用户问题。
如果知识库中没有对应答案，请礼貌告知用户"暂时无法解答，请联系人工客服"。

【参考知识库】：{context}
【用户问题】：{question}
请用简洁、口语化的客服语气回答：""",
            input_variables=["context", "question"]
        )
        
        # 构建RAG链
        retriever = self.vector_store.get_retriever(self.config.retrieve_top_k)
        
        def format_docs(docs):
            return "\n\n".join(doc.page_content for doc in docs)
        
        self.rag_chain = (
            {"context": retriever | format_docs, "question": RunnablePassthrough()}
            | prompt
            | llm
            | StrOutputParser()
        )
    
    def chat(self, message: str, context: Optional[Dict] = None) -> str:
        """对话生成"""
        if context:
            # 注入上下文信息（如订单信息）
            context_str = "\n".join([f"{k}: {v}" for k, v in context.items()])
            enhanced_message = f"上下文信息：\n{context_str}\n\n用户问题：{message}"
        else:
            enhanced_message = message
        
        return self.rag_chain.invoke(enhanced_message)
```

**向量检索实现（vector_store.py）：**

```python
from sentence_transformers import SentenceTransformer
from langchain_chroma import Chroma

class SentenceTransformerEmbeddings(Embeddings):
    """基于SentenceTransformer的嵌入实现"""
    
    def __init__(self, model_name="paraphrase-multilingual-MiniLM-L12-v2"):
        self.model = SentenceTransformer(model_name)
    
    def embed_documents(self, texts: List[str]) -> List[List[float]]:
        embeddings = self.model.encode(texts, convert_to_numpy=True)
        return embeddings.tolist()
    
    def embed_query(self, text: str) -> List[float]:
        embedding = self.model.encode(text, convert_to_numpy=True)
        return embedding.tolist()

class VectorStoreService:
    """向量数据库服务"""
    
    def __init__(self, persist_dir="./chroma_db"):
        self.persist_dir = persist_dir
        self.embeddings = SentenceTransformerEmbeddings()
        self.db = Chroma(
            persist_directory=persist_dir,
            embedding_function=self.embeddings
        )
    
    def search(self, query: str, top_k: int = 3, min_score: float = 0.3):
        """检索相关文档"""
        results = self.db.similarity_search_with_score(query, k=top_k)
        
        filtered_results = []
        for doc, score in results:
            # 相似度转换：距离越小，相似度越高
            similarity = 1.0 / (1.0 + score)
            if similarity >= min_score:
                filtered_results.append(doc)
        
        return filtered_results
```

#### 3.1.3 程序调试与运行

**调试过程：**

1. **嵌入模型加载问题**
   - 问题：首次运行需要从HuggingFace下载模型，国内网络连接超时

   - 解决：使用Flask-CORS扩展允许跨域

**运行情况：**

系统运行稳定，API响应时间在500ms-2s之间（取决于问题复杂度和检索结果数量）。向量检索准确率较高，能够准确匹配用户问题与知识库内容。

```java
@RestController
@RequestMapping("/knowledge")
public class KnowledgeController {

    @Resource
    private RagClientService ragClientService;
    
    @Resource
    private KnowledgeMapper knowledgeMapper;

    @PostMapping("/add")
    public Result addKnowledge(@RequestBody Map<String, Object> params) {
        String content = (String) params.get("content");
        Map<String, Object> metadata = (Map<String, Object>) params.get("metadata");
        
        // 1. 检查重复
        Knowledge existing = knowledgeMapper.selectByContent(content);
        if (existing != null) {
            return Result.fail("该知识已存在，请勿重复添加");
        }
        
        // 2. 保存到数据库
        Knowledge knowledge = new Knowledge(content, category);
        knowledge.setKeywords(extractKeywords(content));
        knowledgeMapper.insert(knowledge);
        
        // 3. 同步到向量库
        boolean ragSuccess = ragClientService.addKnowledge(content, metadata);
        
        return Result.success(Map.of(
            "message", "知识已添加到数据库和向量库",
            "ragSync", ragSuccess
        ));
    }

    @PostMapping("/syncToRag")
    public Result syncToRag() {
        List<Knowledge> knowledgeList = knowledgeMapper.selectAll();
        
        // 1. 清空并重建向量库
        ragClientService.rebuildVectorStore();
        
        // 2. 批量添加知识
        int successCount = 0;
        for (Knowledge k : knowledgeList) {
            if (ragClientService.addKnowledge(k.getContent(), 
                Map.of("category", k.getCategory()))) {
                successCount++;
            }
        }
        
        return Result.success(Map.of(
            "total", knowledgeList.size(),
            "success", successCount,
            "message", String.format("向量库已同步%d条知识", successCount)
        ));
    }
}
```

```python
from flask import Flask, request, jsonify
from flask_cors import CORS

def create_app(config: Config) -> Flask:
    app = Flask(__name__)
    CORS(app)  # 启用跨域支持
    
    rag_service = RAGService(config)
    
    @app.route('/health', methods=['GET'])
    def health():
        """健康检查接口"""
        return jsonify({
            "status": "ok",
            "service": "rag-service",
            "model": config.deepseek_model
        })
    
    @app.route('/chat', methods=['POST'])
    def chat():
        """RAG对话接口"""
        data = request.get_json()
        message = data.get('message', '')
        context = data.get('context')
        
        if not message:
            return jsonify({"error": "消息不能为空"}), 400
        
        answer = rag_service.chat(message, context)
        
        return jsonify({
            "success": True,
            "answer": answer
        })
    
    @app.route('/knowledge/search', methods=['POST'])
    def search_knowledge():
        """知识库检索接口"""
        data = request.get_json()
        query = data.get('query', '')
        top_k = data.get('top_k', 3)
        min_score = data.get('min_score', 0.3)
        
        results = rag_service.search_knowledge(query, top_k, min_score)
        
        return jsonify({
            "success": True,
            "results": results,
            "count": len(results),
            "vector_store_count": rag_service.get_vector_store_count()
        })
    
    @app.route('/knowledge/add', methods=['POST'])
    def add_knowledge():
        """添加知识到向量库"""
        data = request.get_json()
        content = data.get('content', '')
        metadata = data.get('metadata', {})
        
        success = rag_service.add_knowledge(content, metadata)
        
        return jsonify({
            "success": success,
            "message": "知识添加成功" if success else "知识添加失败"
        })
    
    @app.route('/knowledge/rebuild', methods=['POST'])
    def rebuild_knowledge():
        """清空并重建向量库"""
        import shutil, os
        
        persist_dir = rag_service.vector_store.persist_dir
        if os.path.exists(persist_dir):
            shutil.rmtree(persist_dir)
        os.makedirs(persist_dir, exist_ok=True)
        
        rag_service.vector_store.initialize()
        
        return jsonify({
            "success": True,
            "message": "向量库已清空并重新初始化",
            "count": rag_service.vector_store.get_count()
        })
    
    return app

def run_server(config: Config) -> None:
    """运行Flask服务器"""
    app = create_app(config)
    print(f"RAG服务启动在端口 {config.flask_port}")
    app.run(
        host=config.flask_host,
        port=config.flask_port,
        debug=config.flask_debug,
        threaded=True
    )
```
